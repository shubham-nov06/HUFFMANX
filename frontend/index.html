About HuffmanX

LOSSLESS BY DESIGN

Compression, made visible.

HuffmanX is an educational, local-first file compression lab. It demonstrates classic lossless algorithms and verifies restored files with SHA-256.

Algorithms

Huffman, RLE, LZ77, LZW and DEFLATE.

Architecture

Vanilla HTML/CSS/JavaScript frontend with a Python FastAPI backend.

Container

HFX is a custom archive format. It is not compatible with ZIP or other standard archive formats.
